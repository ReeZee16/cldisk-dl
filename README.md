免梯子流量极速下载助手 (Tampermonkey Userscript)

点击下方链接即可通过 jsDelivr 极速安装（需先在浏览器安装 Tampermonkey / 脚本猫 / Violentmonkey 任一扩展）：

👉 [**点击一键安装 cldisk-dl 油猴脚本**](https://cdn.jsdelivr.net/gh/ReeZee16/cldisk-dl@main/cldisk-dl.user.js)

---

## 核心特性

* ⚡ **0 海外 VPN / 代理流量消耗**：自动切换至境内官方高速 CDN 直连通道下载。
* 🛡️ **官方授权认证**：自动携带白名单 Referer，彻底解决 403 拦截。
* 🚀 **智能极速接管**：内置 TLS 链路预热与失焦检测，完美兼容浏览器原生下载与 IDM 32 线程加速。
* 🔄 **自动检测更新**：已配置 `@updateURL` 与 `@downloadURL`，后续发布新版本自动静默升级。
* 🎯 **按需直通**：按住 `Ctrl` / `Shift` / `Alt` 键点击下载链接，可主动跳过脚本直接走原版下载。
